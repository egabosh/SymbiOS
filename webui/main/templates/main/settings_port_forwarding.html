{% if ip_mode == 'only' %}

  1. Open the router's web interface and go to the IPv6 port sharing settings (FRITZ!Box: Internet → Permit Access → IPv6 → Port Sharing).
  2. Add rules for the server as a device (not as a fixed IP):
    ExternalProtocolPurpose
    80TCPHTTP
    443TCPHTTPS
    33TCPSSH (optional)
  3. IPv6 forwards only work with identical external and internal port (e.g. 80 → 80, 33 → 33). A different port can therefore not be mapped over IPv6.
  4. Device-bound rules follow the server automatically when the IPv6 prefix from the provider changes.
