Matrix sender account
Matrix notifications are sent E2EE-encrypted into a single room by a sender account. This works with any homeserver (your own matrix.<domain> or e.g. matrix.org) — the Matrix service does not need to be installed. After saving, verify the new symbios-notify-* device and make sure the sender is joined to the room:
  1. Create a room with encryption enabled (or reuse one).
  2. Invite {{ vars.matrix_user|default:"@sender:server" }} to the room.
  3. Verify its device when it joins, then send a test below.
