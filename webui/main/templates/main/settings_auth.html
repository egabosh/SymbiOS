Login (Authelia)
{% csrf_token %}
Requires a configured mailserver. Users must then additionally confirm with a code or TOTP.
Info

Authelia is an open-source login server that is integrated into Traefik as a forward-auth middleware. After enabling:

  • All web services behind Traefik require a login
  • Users log in against the local LDAP directory
  • Optional 2FA (email or TOTP) as a second factor

Manage users under Users and groups under Groups. Without 2FA, username/password is sufficient.
