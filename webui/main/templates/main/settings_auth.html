Benötigt einen eingerichteten Mailserver. Benutzer müssen sich dann zusätzlich per Code oder TOTP bestätigen.
Info

Authelia ist ein Open-Source-Anmeldeserver, der in Traefik als Forward-Auth-Middleware eingebunden ist. Nach dem Aktivieren:

  • Alle Web-Dienste hinter Traefik verlangen eine Anmeldung
  • Benutzer melden sich gegen das lokale LDAP-Verzeichnis an
  • Optional 2FA (E-Mail oder TOTP) als zweiter Faktor

Benutzer unter Benutzer und Gruppen unter Gruppen verwalten. Ohne 2FA genügt Benutzername/Passwort.
