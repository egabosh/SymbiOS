How it works

External systems are remote hosts managed via SSH from the SymbiOS server. You can run Ansible playbooks from external-services/ on these systems.

  • Add the host's public SSH key (shown above) to the target's ~/.ssh/authorized_keys, or use the "Install Key" button on a system to do this automatically with a one-time password.
  • Playbooks with docs.type matching the system type will be available for that system.
  • Execution happens via SSH with the host's existing /root/.ssh/id_ed25519 key.
