How it works

Assign a physical interface (e.g. wlan0) to an existing Linux bridge. The assignment is applied immediately with ip link and restored after every reboot via /etc/rc.local.

The bridge must already exist and must not be managed by Docker or SymbiOS (bridges named br-*, docker*, symbios_base_services, symbios_services, base-services or services are hidden).

Removing the assignment detaches the interface from the bridge and removes it from the boot sequence.
